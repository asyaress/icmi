# Content Workflow and Go-Live Checklist

## SOP Editorial

1. Kontributor membuat draft.
2. Editor review struktur, bahasa, validasi data.
3. Admin approval publish.
4. Jika perlu, schedule publish.

## Standar Konten per Artikel

1. Judul jelas dan informatif.
2. Slug bersih (tanpa karakter aneh).
3. Excerpt singkat.
4. Thumbnail sesuai rasio.
5. Meta SEO terisi.
6. Kategori dan tag relevan.

## QA Checklist Publik

1. Navbar dan menu berfungsi.
2. Semua halaman utama dapat diakses.
3. Listing dan detail konten dinamis.
4. Search dan filter bekerja.
5. Mobile responsive.
6. Tidak ada broken image/link.

## QA Checklist Dashboard

1. Login/logout.
2. CRUD konten utama.
3. Upload media.
4. Publish/schedule/unpublish.
5. Role permission berjalan.
6. Audit log tercatat.

## Go-Live Checklist

1. Domain dan SSL aktif.
2. Sitemap dan robots valid.
3. Backup aktif dan diuji restore.
4. Monitoring aktif.
5. Training admin selesai.
6. Dokumen handover tersedia.

## Hypercare (7 Hari Pertama)

1. Monitoring error harian.
2. Triage bug prioritas.
3. Fix cepat untuk isu produksi.
