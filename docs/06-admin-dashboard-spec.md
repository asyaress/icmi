# Admin Dashboard Specification

## Role dan Hak Akses

1. Super Admin
- Full akses.

2. Admin
- Kelola konten dan media.
- Tidak kelola role/permission sistem.

3. Editor
- Buat/edit/review konten.
- Publish jika diizinkan.

4. Kontributor
- Buat draft sendiri.
- Tidak bisa publish.

## Modul Dashboard

1. Dashboard Home
- Statistik konten.
- Konten terbaru.
- Quick actions.

2. Content Management
- Berita.
- Opini & tokoh.
- Info media.

3. Taxonomy
- Kategori.
- Tag.

4. Media Library
- Upload file.
- Reuse image/video.

5. Galeri dan ICMI TV
- Album galeri.
- Video list.

6. Static Pages
- Sekilas ICMI.
- Kontak.
- Halaman profil lain.

7. Site Settings
- Logo/favicons.
- Kontak dan sosial media.
- SEO global.

8. User & Access
- User admin.
- Role permission.

## Workflow Konten

1. Buat draft.
2. Review editor/admin.
3. Publish atau schedule.
4. Revisi bila perlu.

## Fitur Pendukung Wajib

1. Autosave draft.
2. Preview sebelum publish.
3. Audit log perubahan.
4. Soft delete + restore.
