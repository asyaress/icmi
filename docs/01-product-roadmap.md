# Product Roadmap (12 Minggu)

## Tujuan Akhir

1. Website publik ICMI Kaltim live dan stabil.
2. Semua konten utama dinamis dari dashboard.
3. Tim admin/editor bisa operasional tanpa edit kode.

## Fase Roadmap

## Minggu 1: Discovery dan Scope Final
- Finalisasi menu utama dan submenu.
- Definisi peran user: `Super Admin`, `Admin`, `Editor`, `Kontributor`.
- Prioritas fitur versi 1.

## Minggu 2: UX + IA + Data Blueprint
- Final sitemap dan user flow.
- Wireframe publik + dashboard.
- Draft ERD dan aturan slug/SEO.

## Minggu 3-4: Foundation Backend
- Auth admin + role/permission.
- Struktur model/migration inti.
- Upload media manager dasar.

## Minggu 5-6: Modul Konten Inti
- Berita, kategori, tag, author.
- Galeri foto/video.
- Halaman statis dinamis (Sekilas ICMI, Kontak, Profil).

## Minggu 7: Frontend Data Binding
- Home page full dinamis.
- Listing/detail berita dinamis.
- Search/filter kategori/tag.

## Minggu 8: Dashboard Completion
- Dashboard statistik ringkas.
- Draft/publish/schedule.
- Activity log admin.

## Minggu 9: SEO + Integrasi
- Meta title/description/OG image.
- Sitemap XML dan robots.
- Integrasi social links, contact, embed video.

## Minggu 10: Hardening
- Security pass.
- Cache dan optimasi query.
- Image optimization dan lazy load.

## Minggu 11: UAT dan Bug Fix
- UAT bersama tim ICMI Kaltim.
- Perbaikan isu prioritas tinggi.
- Freeze fitur.

## Minggu 12: Go-Live
- Deploy production.
- Setup backup/monitoring.
- Training admin/editor.

## Definition of Done (Go-Live)

1. Semua halaman publik utama memakai data DB.
2. Semua modul dashboard inti berjalan normal.
3. Lighthouse/performance sesuai target minimum internal.
4. SOP backup dan recovery sudah diuji.
