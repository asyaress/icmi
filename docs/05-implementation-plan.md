# Implementation Plan (Execution)

## Sprint 1: Foundation

### Deliverable
1. Auth admin dan role permission dasar.
2. Layout dashboard admin.
3. CRUD user admin.

### Acceptance
1. Login/logout aman.
2. Role membatasi akses menu dashboard.

## Sprint 2: Content Core

### Deliverable
1. CRUD kategori dan tag.
2. CRUD berita (draft/publish).
3. Upload featured image.

### Acceptance
1. Konten publish muncul di halaman publik.
2. Slug auto-generate + editable.

## Sprint 3: Opinion + Media

### Deliverable
1. CRUD opini & tokoh.
2. CRUD info media.
3. Listing/filter publik.

### Acceptance
1. Semua listing punya pagination.
2. Search title bekerja.

## Sprint 4: Gallery + ICMI TV

### Deliverable
1. CRUD galeri foto.
2. CRUD ICMI TV/video.
3. Detail gallery/video.

### Acceptance
1. Upload multi-image berjalan.
2. Embed video YouTube tampil stabil.

## Sprint 5: Home Dynamic + SEO

### Deliverable
1. Homepage full dinamis.
2. SEO fields per konten.
3. Sitemap dan meta tags.

### Acceptance
1. Section home bisa diatur dari dashboard.
2. Meta title/description terbaca di source page.

## Sprint 6: Stabilization

### Deliverable
1. Hardening, cache, dan optimasi.
2. QA fix dan UAT fix.
3. Dokumentasi operasional.

### Acceptance
1. Bug blocker = 0.
2. Checklist go-live lulus.
